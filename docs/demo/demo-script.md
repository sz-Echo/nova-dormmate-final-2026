## 录制与配音方式

- 录制：`python simulator/record_demo.py`——8 幕全自动（Playwright 双 iframe 同屏 + 移动端 gdigrab 录窗合成；脚本自启自停 Broker/5510；录制前自动重置 events.json，结束后恢复基线）。单幕重录：`--scene s3`；移动端录窗需微信开发者工具模拟器窗口在屏幕可见（录制时自动置顶）。
- 配音：`python simulator/add_dub.py`——edge-tts（zh-CN-XiaoxiaoNeural）+ 硬字幕烧录 + SRT 软字幕；台词时间轴按 `scene-timing.json` 各幕实际时长自动校正。
- 详细打点：`scene-timing.json`；台词校对表：`dub-lines.txt`；软字幕：`demo-v08r5-subtitles.srt`。
